# PPT Skill 开发方案

更新于 2026-11-16。当前主线为 Agent 规划内容和布局，调用 skill 内置工具，在真实 PowerPoint 中制作与修改，再保存重开、导出和逐页验收。第三方 PPT-MCP 已退出正式代码与分发依赖，旧实现只保留为本机对照证据。HTML 按需展示，不作为排版或转换前置。

## 当前结构

- `SKILL.md` 负责一句话启动、选型、逐页规划、制作、视觉验收和交付。
- `skills/ppt-content-*` 按学术、工作、教学决定选材与口述。内容与风格分开，页型由本次证据关系选择。
- `resources/<场景>/<风格>/` 提供模板元数据、样式、学习记录和验证记录。藏蓝导航 0.5.0 为 ready 源模板，蓝白渐变为 validating 规则包。
- `scripts/powerpoint.py` 是直接控制 PowerPoint 的入口，`ppt_native.py` 实现 COM 操作，`desktop_lock.py` 提供跨副本协作锁。运行时仅需 pywin32，无 MCP SDK 或文件生成库。
- `scripts/check_deck.py` 读取最终 PPTX，核对源图位、时间轴月份及独立发言稿与备注；不能替代实际看图。
- `runs/` 保存每次输入、逐页稿、素材、计划、成片、讲稿、导出和检查证据。`template-analyzer/` 保存私有参考及原始分析，两者都不分发。

## 工作流与边界

附件与一句生成请求足以启动任务。Agent 读完整材料、提取实际图件，为每页落实问题、落点、出处和主图或阅读关系，再从源模板选择、调整或组合页型。复杂正文先试排并看实际导出，之后铺全稿。正式汇报同步交付独立发言稿及相同备注。

控制工具接收结构化操作计划，按完整路径持有目标文稿，并在全批执行时持有共用桌面锁。新稿复制模板或在软件内创建，支持零页起步、对象与分组修改、图表数据、表格、图件、动画、备注和脚本扩展。详细参数及异常恢复见[内置控制流程](../references/powerpoint-native.md)。

工具不替代设计判断。每张正文页先明确作用及主证据，按风格识别特征判断版式。修改后回读真实文字边界，显式保存重开，再导出最终 PNG 检查。自动检查、文件保存和视觉验收分别报告结果。环境缺口与未验证能力如实披露。

目前没有把任意 Markdown 自动排成优质幻灯片的布局编译器。Agent 根据内容规划操作计划，复杂图形可调用可信的本次 COM 脚本。完整对象模型提供扩展入口，不等于全部 PowerPoint 功能已通过测试。

## 验证与下一步

本轮通过独立依赖环境、模板保真、原生对象制作与修改、兼容性及现有后端对照测试，范围和具体数据见[验证记录](native-validation.md)。后续以真实第三方任务继续验收内容、图件选择、讲稿和页型适配；跨 Office 版本、复杂公式、特殊媒体和宏行为需单独验证。无需为了补充验证恢复旧 MCP 作为正式依赖。
