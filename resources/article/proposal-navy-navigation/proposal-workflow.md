# 藏蓝导航开题汇报逐页制作指南

使用 [0.5.0 源模板](template.pptx) 和[正式预览](preview.png)核对风格。按[模板复用规则](../../../SKILL.md#按内容复用模板)先完成内容，再查找相符页型或组件。下文页码用于定位源模板对象。正文按[内容与构图选择](content-design.md)落实图文关系。

## 开始画之前

1. 读报告正文、表格、图注、附图和参考文献。为上屏的关键主张、数字、方法和图记录来源位置，分别识别文献结果、本课题已完成工作、待开展方案和机理假设。题目、条件或时间冲突时，以已确认版本为准，其余记入待确认项。
2. 先从报告形成论证，再定目录和页数。按[内容与构图选择](content-design.md)核对重要内容的去向。背景交代实际需求、具体问题及研究必要性，文献梳理论证缺口，目标说明要回答或建立什么，内容列出各项工作和产出，方案说明怎样验证。技术路线、阶段成果、可行性、进度和参考文献按材料与场合取舍，不能为了套既定页数而删除论据。
3. 在本次 `slides/*.md` 为每页记录本页问题、实际正文和图、来源及研究状态、口述与转场，再决定布局和复用方式。逐页补一句布局理由，例如“第 10 页只取左栏短标签，右侧留给横向流程，因为主图要连读四个状态”。必要的论据、条件和解释留在页面，展开推导和读图引导放进[独立发言稿](../../../references/speaker-script.md)与备注。
4. 从本次实际提纲生成目录和导航，按下节准备可复制的共用框架。结合 `learning.md` 的复发项选择试排页，从开题必要性、模型对应或验证设计中覆盖最容易讲不清的关系。将逐页稿的实际正文、图件和关系交给绘制步骤，按[试排与导图核对](../../../references/visual-quality.md#试排与导图核对)检查。如果源页约束导致关键条件、标签或证据被挤掉，调整构图后重导再铺全稿。

## 共用框架与正文组件

在工作副本用 `snapshot` 查对象。需要重组或重绘正文时，可取第 03 页作为起点，保留 `导航底带`、`当前章轮廓`、`导航栏目*`、`导航英文*`、`导航分隔线*` 和正文标题 `T010`、`T011`。这些名称只用于定位，具体操作使用确认后的名称或 ID。按实际需要处理 `标识占位`，清除未用的正文占位、装饰和残余连线，设置真实章名和高亮。用已调好的起始页复制同章页面，统一处理章名、高亮和标题起线。导航调整见[维护说明](maintenance.md#导航调整)。

使用内置工具时，可在 `create.slides` 指定用到的源页，并用 `duplicate_slide` 复制已经调好的章节起始页。源页号用于创建，复制后按工作副本回读得到的页面 ID 或标签定位。按最终页序移除未用于汇报的起始页。见[控制工具](../../../references/powerpoint-native.md#计划输入)。

| 需要表达的关系 | 可借用的组件与构图选择 |
| --- | --- |
| 需要讲透背景，材料只有一张关键对象图 | 借第 03 页的短标签、浅灰说明区和证据框。主图放在能保持细节可读的一侧，正文按需求、限制和研究切入组织，可以用连续短段落。中心竖图和双侧汇聚采用实际有两条动机的情形。 |
| 对照两种模型，或把整体和局部对应起来 | 按实际图幅决定并列或主图加局部放大。可借第 10 页的短标签或证据区，把两幅图对齐到同一对象或位置。共用条件放在靠近两图的位置，引线只连接可指认的对应点。 |
| 用户强调验证，材料给出多个观测量 | 可复用第 05 页的分层短标签和细实线框。按观测组数排对照区，各组就近标明测点、读数、模型量或判据。若证据集中在装置图，先把测点标在图上，再安排图旁说明。 |

确认相同构图能承载同类证据时，直接复用对应整页。构图可以随正文变化，紧凑标题、藏蓝短标签、中性说明和相应实虚线保持各自用途。各页借用适合它的组件即可。

## 源模板页型索引

这张表用于查找现有版式及对象。只有内容关系相符时才按整页构图使用。

| 源页 | 这一页负责讲什么 | 上屏内容与排版细节 |
| --- | --- | --- |
| 01 目录 | 汇报怎么展开 | 左侧保留藏蓝块与居中目录标题，右侧从统一章页映射生成编号和标题。章数变化时重排纵向间距，沿同一条编号线与标题线对齐。 |
| 02 背景 | 为什么值得做，以及具体卡在哪里 | 三卡各带一个证据或概念图、一句解读，沿“需求、已有支撑、缺口”阅读，底部一句话落到课题切入。只有一张主图时改成两段论证配单图，给主图足够宽度。 |
| 03 意义 | 不同动机或证据如何汇到同一问题 | 中间竖图为主，左右浅灰卡分别给应用和学术理由。主题改为机理时，左右可分别解释局部条件与整体现象，箭头均指向中心，图注说明是观察、模型结果或假设。 |
| 04 文献对比 | 两项工作对当前研究问题提供什么 | 两栏各放作者年份、来源、一项关键信息或一张证据图、“完成的工作”和“本课题可借鉴处”。图高或基线一致，各自保持宽高比。用共享底条归纳待验证的缺口。对比对象可按方法、情境或证据选择。 |
| 05 目标与任务 | 一句总目标怎样落到若干工作 | 上方目标条，下方等宽卡写短任务名、关键工作和产出，底条放共同科学问题。目标和内容较复杂时，用下方两页变体。任务数取自报告，统一卡片的标题、正文和末句基线。 |
| 06 技术路线 | 前一步的产出如何进入后一步 | 用任务短语做阶段名，说明卡写本阶段关键动作和送给下一段的产出。尖角对准对应阶段，流程箭头按依赖排列。存在并行支路就分支后汇合。 |
| 07 多输入与证据 | 不同输入各怎样支撑同一证据 | 左侧两组输入分别放说明和小图，各用一条线接中部核心证据，右栏解读证据。用短标签区分输入与真正引用的结果。 |
| 08 输入汇聚 | 多条工作怎样汇成一个指标、模型或产出 | 两个输入先向下汇合，再连接共用图表与解读。保证汇合点、主线的去向清晰。 |
| 09 并行方法 | 需要哪些方法共同回答问题 | 中心写要回答的问题，四周按实际数量布置方法。每卡写方法及它产出的观察量或判据，对齐编号和卡片，避免读成连续步骤。 |
| 10 材料与方案 | 变量、样品或对象怎么选，方案怎么实施 | 一侧给准备、对照和选择依据，另一侧给主示意图或横向流程。留出流程和引线宽度。图已有的步骤可在文中压成对照条件和判断指标。 |
| 11 关键技术与创新 | 难点在哪里，改动发生在哪一环 | 分块写难点、拟采用的办法、与基线做法的区别及验证方法，短标签贴齐图框。图中文字标注改动位置，创新陈述与当前研究状态一致。 |
| 12 已有工作组合 | 一张主图与若干补充图如何支撑同一观察 | 高图作主视觉，右侧按对照条件或证据类型分组。组名、子图标识与图注按同一顺序排。 |
| 13 多图结果 | 同类观测在不同条件下怎么比较 | 上方写具体发现，以相同方向、可比尺度和一致的图例组织多图。组间条件不同就在图注中说明，底部给研究启示及适用范围。 |
| 14 证据收束 | 哪些图共同支撑一个结果 | 窄槽给局部图、样品图或简图，宽槽留给定量图。保留轴标签、单位、样本量或误差标记。底部写证据支持的结论和限制。第 12–14 页以真实完成的工作为前提。 |
| 15 可行性 | 关键输入具备到什么程度 | 用横排说明呈现已有资源、已知依据、关键依赖及风险应对。标签写可查证的状态，如“设备可用”“需外部验证”，避免只写评价词。 |
| 16 进度 | 哪项工作何时完成，交付什么 | 左列阶段及可核对的交付，中栏起止月，右栏统一时间轴。按同一月份定义画条，重新核对文字、条端与轴刻度。已完成、准备和后续计划按材料标注。 |
| 17 参考文献 | 听众怎样定位已引用工作 | 收录汇报实际引用的核心条目，正文用同一编号或作者年份。续行与文献正文左缘对齐，条目较多时拆页。 |
| 18 结束 | 将注意力转回交流 | 保留中心致谢或交流提示，身份来自本次材料。正式开题可配对制作全幅藏蓝封面和结束页。封面用白色正式题目作主视觉，身份、单位和日期另组，长题目按语义断行。两页使用同一标识和对齐方式，标识以本次材料为准。 |

### 两种高频适配

- **分开目标页和内容页。** 报告有独立的目标与任务时，可用第 05 页组件分别组织。目标页按“总目标 → 可评价的分目标”分出箭头，每张卡说明要建立或判断的关系。内容页让每张卡包含“任务名、做什么、交付什么”。两页分别安排正文层级、容器尺寸和连接关系。报告需要用多个产出解释同一问题时，从各卡底部汇到同一底条，线端落到对应卡或结论框。画完只看标题、卡片末句与箭头，也应能读出一页分解、一页汇合。
- **分开工序页和验证页。** 同章的连续工序可重复第 10 页骨架。工序页的主图展示步骤、状态转换和关键控制，验证页展示“比较谁、测什么、按什么判断”。整体图加放大图时，用引线标出放大区域，分别标注两幅图解释的尺度。机理图在图注标明观察、计算结果、方案或假设，页底可写后续怎样检验。

缺少配图时先核对是否确实无图，还是未提取到。可绘制有具体对象、位置和关系的原生示意，或为适合文字表达的内容重排对照；需要解释几何、装置和局部结构的页面不能只换成普通文字卡。示意图标明用途，定量图使用可靠数据。成品里的数值精度、已有成果和身份信息以可核实材料为准。

## 逐页刻画与交付检查

- **导航和标题。** 标识、浅色高亮和正文箭头标题沿用源模板的层级。按实际章数重排，检查白色异形与页顶相接、末项贴边收口、两种语言间距和分隔线避让。正文切换页型时维持共用标题起线。
- **图文和容器。** 有一张清楚的主图或主阅读关系。等权对比让两栏同起线、图注同层级。细虚线用于证据图框，细实线用于任务卡。标签贴齐或嵌入边框，段落起线、内边距和线条端点统一。图内的标尺、符号、对照名、裁切边界和来源在导出尺寸可读。
- **文字与内容。** 先隐藏讲稿逐页阅读，再回报告核对论证和信息遗漏。背景只剩对象示意、文献图没有发现与限制、技术方案只剩方法名，均应重写内容。实际回读文字边界，检查孤字、溢出和相邻边界。拥挤时先重排或拆页，再压缩不必要的重复和微调字号，不能删除理解所需的依据。核对同页标题、配图与结论，以及跨页术语、单位、日期和研究状态。修改后重新导出。
- **成片。** 用目标 PPTX 实际导出页图，逐页检查。有图位的成片必须放入有信息的图件，或移除图框并按文字比较页重排。灰底大框内居中的段落、用文字箭头代替能绘出关系的图、相邻页复述同一任务、计划终点与时间轴不一致，均须返修。保存后从输出路径重开，核对页序、导航、图件、发言稿与原生对象，确认清除废弃模板页和占位字。记录尚待确认的内容与检查限制。视觉和编辑能力细则见[页面验收规则](../../../references/visual-quality.md)。
