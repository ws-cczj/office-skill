# 藏蓝导航复用与验收规则

正式生成使用当前任务材料、[0.5.0 源模板](template.pptx)、[内置预览](preview.png)和本包规则。按[正文制作指南](proposal-workflow.md)复用共用框架及适用组件，按[内容与构图选择](content-design.md)安排论证、证据及图示。

| 核对项 | 制作与验收 |
| --- | --- |
| NAV-01 导航高亮 | 复用贴顶自由曲线，按实际栏目宽度调整两肩和末项收口。从导图确认浅色区与页顶连接。 |
| NAV-02 文字层级 | 当前栏中英文在轮廓上层。换章后回读英文实际色值：高亮 `#14386C`、普通 `#F0E2D6`。查看首项、中间项和末项，确认字面清楚且与相邻栏分开。 |
| NAV-03 正文组件 | 保留紧凑箭头标题、短藏蓝标签和中性说明底色。细虚线表示证据区，细实线表示任务卡。卡片用加粗短锚点引出命题，技术要点较充实时可在段内局部加粗核心对象、关键条件或结论短语。压缩文案时保留支撑依据和实质参数、方法细节，篇幅随阅读与证据关系调整。 |
| NAV-04 图件取用 | 直接支撑论点的实验、模型或文献对照可作主视觉，就近说明读图重点和适用范围。仅作方法借喻的远缘图降为辅助对照或改用聚焦的机理对照示意。多步工艺、物理或化学机理、剖面结构、细观几何和实验对照优先复用并洁净裁剪源稿内嵌高质量图示或核心文献原图。原生简单矩形和箭头只用于宏观流程框图或极简受力模型。文献原图在图框底部就近标注简短作者年份或文献编号。裁剪多面板图后放大复核四边，清除相邻面板残留的编号、标尺碎片和箭头，保留所用面板的必要图例与标尺。实拍中的杂物、包装或反光遮挡干扰读图时，二次裁剪聚焦主体，必要时降权。超宽复合图纵向堆叠挤压正文或图注时，拆页、横排或局部裁切。 |
| NAV-05 章节一致 | 目录、导航和讲稿共用实际章页关系。顶栏主导航宜保留 4–6 个核心章节，参考文献、致谢等单页收尾用页内标题标识。同一主章连续多页展开时，优先用 `主章｜本页子主题` 作标题。关键科学问题、研究特色与创新点使用独立页或占据所在页的主视觉层级。 |
| NAV-06 时间轴与讲稿 | 甘特图以本次阶段起止月安排刻度和条端。每行呈现阶段名称、起止月份及一行具体任务或交付说明，单看页面应能辨认各阶段实际工作。文件重开后核对页序、指图和备注。 |
| NAV-07 正文构图 | 读法相符时复制整页，局部适用时重组组件，其余页面可用共用导航框架重绘。卡宽、图幅和正文分组随材料确定。按下文 [正文构图与文献对照](#正文构图与文献对照) 轮换版式并核对各页新增信息。 |
| NAV-08 从导图验收 | 将导图放大到可读尺寸。检查卡片末行的留白及词组断行。先从画面指出可读的依据、限定与对应关系，再对照逐页稿。连线未触及所指对象或条件只在口述时出现，记录该项未达。 |
| NAV-09 图义与端点 | 逐根指出端点、方向和变量含义。画界面作用时先找两对象实际相接的边界范围，再把标记接到该范围。相近术语分别检查其可指认的几何含义。转角、弯矩等旋转量使用平滑圆弧对象，禁止用粗粒度多段折线拼接。位移用有方向的直箭头。 |
| NAV-10 口述随图 | 终版排定后核对逐页稿、独立稿、备注和 QA 中的方位指代。正文移到另一处时更新这些文字。按最终画面顺序用可直接朗读的句子解释对象、条件与转场。 |
| NAV-11 必要依据 | 背景从材料选一个真实使用场景或后果，写明关联的具体问题、现有证据边界和研究切入点。源稿有具体试件或材料、核心工况参数、对照分组、表征或测试手段、建模边界或验证判据时，对应背景和方案页保留实质参数与方法细节。模型对照分开写共用条件和变化工况。验证分组分别写出各组输入、观测量及判断用途。 |
| NAV-12 核心公式 | 论证依赖核心数理推导、控制方程或定量判据时，按全稿论证精选 2–4 个核心方程或定量定义直接上屏。就近标注关键物理量或项的含义与适用条件。概念框和源稿公式编号不能替代公式。纯文本公式含 `√`、`∫`、`∑` 等特殊符号时，在导出 PNG 上放大核对基线与下方说明的间距。出现下沉或挤压时，采用等价幂次写法（如 `(a² + b²)^(1/2)`）、统一数学字体或使用原生公式对象，再导出复核。 |

## 正文构图与文献对照

- 禁止连续 3 页及以上套用完全相同的“左虚线框＋右文字＋底部灰条”。连续图文页主动交替主图和正文的左右位置。底部通栏灰条只在有收束判据、边界限定或待开展结论时使用。
- 总分目标用总框、向下分支箭头和分栏卡。多任务汇聚机理用分栏卡和底部汇流连接线指向总框。两方证据支撑核心机理时，用左卡 → 中图 ← 右卡显示各自如何支撑。
- 多步工艺或实验用左挂短标签与右侧缩进正文组织条件、步骤和观测。细节放大可用实线要点框和虚线引出线连接右侧图框，指明局部位置。
- 有多篇直接对标的核心文献和可用原图时，国内外研究现状优先按主题拆为 1–2 页双栏文献对照页。每栏依次呈现作者年份及期刊卷页、核心文献原图、已有工作、对本课题的借鉴与边界，底部通栏写从两栏证据推出的待开展工作或研究缺口。
- 科学问题界定待解释的现象及条件，研究目标与任务说明量化产出，技术路线交代环节之间的数据与验证如何交接，特色与创新说明可检验的贡献。相邻结构页须提供各自新增的信息，禁止更换标题或版式后重复同一套任务大纲。

正文、页脚、图注、备注与独立发言稿的行首和行内均禁止源稿章节定位（如 `§x.x`）、源图表公式索引、编号映射、内部版本字样及制作自注。映射与作图说明留在 `slides/*.md` 或 `qa/report.md`。保留正常学术引用、面向听众的图题如“结构示意图”及必要的单位和标尺。自动检查用于核对已列文件条件，内容与风格依据终版画面验收。源模板的尺寸、可编辑范围和环境记录见[模板验收](validation.md)。
