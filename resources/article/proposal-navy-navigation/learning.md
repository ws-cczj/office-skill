# 藏蓝导航复用与验收规则

正式生成使用当前任务材料、[0.5.0 源模板](template.pptx)、[内置预览](preview.png)和本包规则。按[正文制作指南](proposal-workflow.md)复用共用框架及适用组件，按[内容与构图选择](content-design.md)安排论证、证据及图示。

| 核对项 | 制作与验收 |
| --- | --- |
| NAV-01 导航高亮 | 复用贴顶自由曲线，按实际栏目宽度调整两肩和末项收口。从导图确认浅色区与页顶连接。 |
| NAV-02 文字层级 | 当前栏中英文在轮廓上层。换章后回读英文实际色值：高亮 `#14386C`、普通 `#F0E2D6`。查看首项、中间项和末项，确认字面清楚且与相邻栏分开。 |
| NAV-03 正文组件 | 保留紧凑箭头标题、短藏蓝标签和中性说明底色。细虚线表示证据区，细实线表示任务卡。标签、框和正文保持各自层级。 |
| NAV-04 图件取用 | 从本次材料择取支持主张的图件，紧邻图件说明读哪个量、区域或现象及其适用范围。放大核对裁切边缘、必要标尺、图例和子图编号，清理无关相邻面板的残留。需要关系图时按实际对象和标注重绘。文字足以完成任务时取消空图槽，按正常正文排版。 |
| NAV-05 章节一致 | 用本次内容确定章名和页序，目录、导航和讲稿共用同一章页关系。目标表述要回答什么，任务给产出，方案给验证方法。 |
| NAV-06 时间轴与讲稿 | 以本次阶段起止月安排刻度和条端，文件重开后核对页序、指图和备注。 |
| NAV-07 正文构图 | 读法相符时复制整页，局部适用时重组组件，其余页面可用共用导航框架重绘。卡宽、图幅和正文分组随材料确定。相邻页应能读出各自新增的信息。 |
| NAV-08 从导图验收 | 将导图放大到可读尺寸。检查卡片末行的留白及词组断行。先从画面指出可读的依据、限定与对应关系，再对照逐页稿。连线未触及所指对象或条件只在口述时出现，记录该项未达。 |
| NAV-09 图义与端点 | 逐根指出端点、方向和变量含义。画界面作用时先找两对象实际相接的边界范围，再把标记接到该范围。相近术语分别检查其可指认的几何含义。转角用弧线或合适的符号，位移用有方向的直箭头。 |
| NAV-10 口述随图 | 终版排定后核对逐页稿、独立稿、备注和 QA 中的方位指代。正文移到另一处时更新这些文字。按最终画面顺序用可直接朗读的句子解释对象、条件与转场。 |
| NAV-11 必要依据 | 背景从材料选一个真实使用场景或后果，说明它关联的具体问题，再写已有证据到哪里和研究切入点。模型对照分开表达共用条件与分别比较的工况，保留对应量和判断用途。验证分组分别写出各组输入及要回答的问题。 |

上屏标题、图注和备注使用面向听众的正式表述。试排目的、布局指令和核对过程写入工作稿或 QA。自动检查用于核对已列文件条件，内容与风格依据终版画面验收。源模板的尺寸、可编辑范围和环境记录见[模板验收](validation.md)。
