# 多图合成一张 Visio 图

先读完所有参考图，按用户的目标合成一张有明确阅读顺序的图。保留临时来源对应关系，方便在最终导出时逐项核对；不要求用户先填写模板或逐图分工。

1. **分配来源。** 用户指定某张图作布局、结构、标签或照片依据时，按指定用途取用。未指定时，用清楚的总览定构图，以细节图补充对应部位。借用构图或配色的图不提供新的结构关系、数据或结论。
2. **对齐对象。** 同一对象的不同视角，先用可辨认的端面、孔位、编号或部件关系建立对应，再选一个主视角；看不见的深度和边不能只凭一张图猜出来。不同样品或条件保留为独立面板，不把它们拼成一个对象。截图局部要定位到全图相同区域后再替换。
3. **解决冲突。** 用用户明确指定的来源决定该项内容，其次考虑可辨识度和来源与该项信息是否匹配。若标签、尺度、结构或科学结论仍冲突，只询问会改变结果的那一项；可以先画没有争议的部分。保留图片实际的比例、单位和比例尺，不把不同拍摄倍率当作可直接比较的物理尺寸。
4. **合成与检查。** 将确认的部件组成原生 Visio 对象，用分组和连接线表达关系；照片和显微纹理按原像素裁入对应区域。保存重开后回查关键对象来自哪张图、引线是否指到正确部位、重复内容是否只画一次，以及整页是否仍准确表达用户的主线。
