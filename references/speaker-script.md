# PPT 逐页发言稿

面向现场讲述的 PPT 同步规划上屏内容与口述。开题答辩、工作报告、教学展示分别按对应的场景内容子 skill 编写。本文件规定交付与核对方式。

逐页文稿记录画面、可完整朗读的口述及必要的转场。按最终 PPT 页码和实际标题把口述汇总为独立发言稿，例如 `output/发言稿.md`。用 `## 01｜本页标题` 标记每页，其下放需朗读的正文，把同样正文写入对应页备注。时间提示和制作记录可保存在逐页文稿，便于独立发言稿与备注逐条核对。换页、拆页和改图后同步更新三处。

- 上屏文案、备注和独立稿均用汇报人或课题组的第一人称现场视角陈述自身工作。按实际状态写“我们已完成”“本研究拟采用”或“右图展示了”。禁用“报告记载”“报告列出”“右图是报告提供的”“进度按报告修订版”等审阅口吻。外部研究用客观第三人称，如“文献[x]表明”，并点明出处。
- 按听众阅读顺序分句，用与实际版面相符的指图词。术语先解释再用缩写，避免逐字读卡片和留下未完成的口述提示。
- 讲稿可补充图的阅读和方法理由，条件、数字、引用、结论及完成状态与 PPT 取同一材料。口述顺序由实际画面和本次汇报要求决定。数字与专名来自当前任务的可核实材料。
- 有明确时长时给各页分配时间并通读检查，给机制、验证和关键图较长时间，概览与过渡简短。自行估时须标“预计”，实际试讲时复核。交付前从 PPTX 重开回读，逐页核对备注和独立稿的内容及顺序。
