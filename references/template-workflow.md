# 单一风格模板制作与验收

适用于按参考图制作空内容模板、编写外部制作 Prompt、验收交回的 PPTX。每轮选择一个风格。正式汇报的材料、逐页讲稿、备注和研究数据在使用模板时准备。

## 从截图确定页型

1. 查看原图并确定每张实际页面的边界。以清晰大图为细节证据。缩略图用于辨认结构，模糊和遮挡处记录为未知。标出截图边框、界面、水印、外部阴影与身份信息的排除范围。
2. 按「用途｜内容区块与相对位置｜阅读关系」建立一次页型清单，附参考区域。三列并列证据、两侧向中心汇聚、左标签与右任务卡分别是不同结构。同骨架的章节状态、题名、素材、数量或密度变化共用一页；页型编号与最终 PPTX 页序一一对应。若调整清单，在交付表写明合并或增补依据。
3. 对清晰页按实际页面宽高归一化，记录会影响复现的页头比例、正文边距、主栏/辅栏宽度、共同对齐线、卡片高度与间隙。单列关键组件的轮廓连接、线型、字级、填充和箭头方向。标明哪些是截图读数、哪些是实施值；明确截图模糊时能核对到哪一级。

## 制作和对照

- 用可编辑的文字、形状、自由曲线、线条和图文占位制作，一种页型保留一个可直接复制的页面。共用页头、颜色和字号等组件优先复用母版、布局或对象组；栏目文字、当前章状态和正文占位应能在约定的编辑位置修改。图片占位可替换，真实图片在使用时按比例插入。需要形状模拟时写明编辑方式。
- 先完成一个代表页，导出后把参考与成片按同样的 16:9 页面边界和尺寸并排比较。放大检查最具识别度的组件，再看正文比例与层级；通过后将共用组件用于其余页型。在不同的现有页型上覆盖至少两种必要的导航状态；如果风格没有导航或参考只支持一种状态，按实际覆盖范围记录。
- 对每个清晰页查看整体和关键局部，核对拓扑、位置和尺寸、线型与圆角、色块面积和字级。用归一化数值记录会影响验收的偏差，再根据参考清晰度及偏差的实际视觉影响裁定。轮廓连接、主体布局、虚实线、箭头关系任一关键项失配就修该页并重导。对缩略图可见的结构做同样的整体核对，无法确认的细节写入简表。

## 交付与独立验收

- 制作交付为一份只含中性占位的 PPTX、一页一张真实导出 PNG，以及简表「页码 / 页型 / 参考区域 / 编辑入口 / 剩余差异」。发送给外部 AI 的 Prompt 要自包含：以附件为主、给本地路径作备选，写明去重清单、关键造型、交付格式和验收边界。只需简短记录，不要求长设计报告、额外试制文稿或整页重绘脚本。
- 验收收到的文件时保留原件，在副本里按[内置 PowerPoint 流程](powerpoint-native.md)打开、核对页数、导出并逐页对照。确认每个框架都有独立用途和空间结构，检查导航状态和图文占位的编辑入口。空内容模板的用途是建立版式；无需用真实课题成片来验证它。
- 在同一个验证副本内复制代表页，替换一条长中文标题和一个不同宽高比的测试图，按风格检查当前章切换。设置字体后回读文本实际边界，检查图像比例、位置、对比度与截字；保存重开后导出核对。只在验收报告记录试填结果，交付模板保持空内容。报告逐页给出通过、返修或证据不足及其依据，使用 [通用视觉检查](visual-quality.md) 处理实际边界和渲染差异。
- 通过本轮验收并被选定入库的源模板按 [资源规范](../resources/README.md) 登记为 `source`，关联同版本的真实导出预览和验证记录。正式汇报按内容挑选、调整或组合源页型。用已有组件绘制新变体时，核对图文关系及选中风格的识别特征。
