# 工作汇报内容与发言稿

## 选材和编排

先确定听众听完要知道什么或决定什么。取本期范围、目标、实际数据、关键变化、证据和依赖。指标展示统一时间窗、口径、单位和来源，预计值与实际值分别标记。只有用户材料支持时，才给责任人、日期和承诺。

| 汇报任务 | 主线和选材 |
| --- | --- |
| 例会与进展 | 当前状态、与计划的差异、造成影响的因素、下一行动。只展开改变判断的进展，详细记录留备注或附录。 |
| 复盘与总结 | 预期、实际、原因与可验证的证据、下一轮改进。把观察到的变化与对成因的推断分开说。 |
| 决策与协调 | 先说需要听众决定或协调的事项，再给制约条件与可比选项。摆清各选项的收益、代价和依赖，结尾复述待决事项和已确认的下一步。 |

趋势页给时间和基准，对比页统一口径，计划页清楚标出责任、交付和里程碑。缺少可比较数字时用事实表述并标出数据缺口。需要另选视觉模板时由主 skill 处理。

## 逐页口述

先报本页结论，然后指向指标、里程碑或对比差异，说明它对交付或决策意味着什么。讲风险时交代影响范围、已知条件和需要谁协作，区分现状与可能后果。结尾重申听众需要作出的决定，或下一次可以核查的交付。按[共同发言稿规范](../../references/speaker-script.md)准备独立稿和对应页备注。
