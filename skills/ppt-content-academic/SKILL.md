# 学术 PPT 内容与发言稿

## 选材和编排

从报告、论文、表格、图注及其书目确定需要讲的科学问题。为上屏主张记录来源和研究状态，区分文献结论、本课题已完成、待开展及假设。图像承载判断时，保留可读的对照条件、图例、单位与统计限定。每页先写一句听众应记住的话，再选原图、可复核的自绘图或文字对照。

选材及写逐页稿前，对照各章的关键设备型号、试件参数、工况数值、边界条件、时间节点和符号定义。发现冲突，在任务简报与 `qa/report.md` 记录各方表述及来源，在交付说明中明确请作者核实。成片使用各处均有依据的保守表述，或标注待核对项。禁止凭猜测选择或统一冲突值。

### 从详细报告到可读的页面

先提炼能展开讲述的论证内容，再压缩成投影片；不要从章节标题或模板卡片直接生成关键词。围绕本次要回答的问题，在逐页稿或 QA 简要记录 `原文位置与关键信息 → 上屏页/口述/省略及理由`。记录承担论证的事实、比较、方法及限制，不逐句登记，也不要求所有原文上屏。缺口、研究必要性、关键条件和判断依据不能整体迁入讲稿。

逐页稿必须有实际要显示的正文，而不只是“放目标三卡”“配一个示意图”等布局意图。压缩时保留谁、在什么条件下、做什么或得到什么，以及它对当前问题的意义。短标题、公式、标注可以是短语；承担解释的正文须表达可理解的命题，不能整页都是“模型对应、峰值、能量交换”等名词。

上屏文案、独立发言稿和 PPT 备注用汇报人或课题组的第一人称现场视角介绍自身工作，例如“本研究拟采用”“右图展示了”。禁止“报告记载”“报告列出”“右图是报告提供的”“按报告修订版”等旁观转述。外部证据维持客观的第三人称，如“已有研究指出”“文献[x]表明”，准确归属结论。源文档的内部定位、编号映射、制作自注和版本字样只留在 `slides/*.md` 与 `qa/report.md`。

一页可聚焦一个问题，但仍需给出理解答案所需的依据。文案放不下时先比较重排、换页型和拆页；不默认删成每卡两行，不靠持续缩小字号补救。也不整段粘贴报告：按“主题句＋必要事实/比较＋承接”组织文字，用图解释适合图示的部分。具体文字量由阅读效果决定，不设置通用字数、卡片数或图文比例。

多行卡片用**加粗短锚点**标出主题词或结论短语，紧接必要事实、条件或解释。同页锚点分别指向有区别的对象、判断或产出。

| 汇报任务 | 主线和选材 |
| --- | --- |
| 论文解读 | 从论文要回答的问题，推到作者的设计或机制，再用核心结果图回答。保留关键对照，收尾讲适用范围及仍开放的问题。 |
| 组会进展 | 从前次问题进入这次实际进展。挑能解释变化或异常的证据，分清已完成、当前解释、下一步和需要讨论的点。 |
| 开题 | 从背景和文献缺口进入目标、任务与验证。目标写要确定的关系，任务写工作与产出，方案写对照、观测和判据。关键科学问题、研究特色与创新点应获得独立页或所在页的主视觉权重。阶段成果只用用户提供的证据。 |
| 答辩 | 用研究问题组织贡献、方法和结果。每项结论指向一条证据，并说明适用条件或局限。 |

采用藏蓝导航开题模板时，按[逐页制作指南](../../resources/article/proposal-navy-navigation/proposal-workflow.md)选择支持这些关系的源页型。图件解释、术语定义和方法理由可写进讲稿，关键数据和图读法保留在投影片。

### 图件与公式

- 直接支撑本课题主张的模型、实验图或文献对照可作主视觉。仅能类比方法的远缘文献图不得独占主画幅，降为辅助对照并写明适用边界，或改用聚焦的机理对照示意。
- 多面板文献图裁成子图后放大检查四边，清除相邻面板残留的编号、标尺碎片和箭头，保留所用面板的必要图例、标尺与数据。实拍出现杂物、包装或反光遮挡时，二次裁剪聚焦主体，仍妨碍读图则降为次级佐证。纵向堆叠超宽复合图挤压图注或正文时，拆页、横排或只裁取有比较价值的局部。
- 当材料以核心数理推导、控制方程、守恒关系或定量判据支撑论证时，按论证需要选出最核心的 2–4 个方程或定量定义直接上屏，紧邻标出关键物理量或项的含义及适用条件。纯文字概念框和公式编号索引不能替代方程本身。

## 检查内容是否讲清楚

绘制前只读逐页稿中的问题、落点和主证据，检查听众能否顺着它们理解论证。按本页用途检查，不要求每页包含所有项目。

| 页的用途 | 具体检查 |
| --- | --- |
| 背景与意义 | 在一页或连续几页中讲清实际场景/已有认识、具体困难、现有评价或解释为何不足，以及本课题为何值得做。对象示意只能解释“是什么、在哪里”，不能独立代替“为什么研究”。需求和缺口须由材料支持，不为凑结构编造危害或声称无人研究。 |
| 研究现状与缺口 | 说明已引用工作解决了什么、证据支持到哪里、仍未覆盖什么。缺口能从前面的证据推出；不把按作者排列的摘要直接当作论证。 |
| 目标、任务与方案 | 目标可对应后续判断，任务有明确产出，方案交代对照、观测和判断依据。仅列方法名称时，补出该方法回答的问题；材料未给出的条件和判据保留未知，不编造。 |
| 结果与机制 | 画面上能找到支撑落点的对象、趋势或关系。区分观察、解释和待验证假设；概念示意不能替代实测证据。 |

相邻页各自回答一个问题。开题的目标页说明要回答的问题或要建立的关系，任务页说明工作及产出，方案页说明怎样用对照、观测或判据验证。多页讨论同一主题时，在逐页稿写明每页新增的关系、产出或验证信息。新增信息不足就合并或重新分工。逐页稿应说明图里看什么、为什么支持本页落点；图片数量、卡片数量和页数随证据需要确定。

同一主章节连续 5 页及以上时，在内容区顶部或副标题用当前子阶段名称或进度序号标明论证位置。页内路标随推进更新，沿用主导航结构。

整稿中，将每项研究问题与首个回答它的方案页对上。重要方案从所用输入、比较条件与观测量中选出会影响判断的部分，明确观测属于实测、派生还是模型估计。共同条件和比较中变化的工况分别写清。方法范围超出证据时保留判断边界，例如有图像能够核对变形位置时，仍需单独说明量化推断所需的其他记录。

绘制前做两次不同的阅读：先只读拟上屏内容，检查听众能否理解本页主张及其依据，术语和图例是否足够；再对照报告，检查必要事实、论证环节和限定是否在压缩中消失。隐藏讲稿后若整页只能读出主题而读不出解释，先重写。背景未论证必要性、文献仅剩配图、目标/任务/方案只有名词、可行性仅有评价标签，都不能因“后面会讲”或“口述补充”而通过。

研究对象、模型差异、边界/测点或局部结构是理解条件时，将这些内容落实到原图、可核查示意或明确的对应关系中。几个方法名加箭头只解释顺序，不能顺带证明已解释对象与机理。对照页保留材料给出的可比条件；压缩文案时不能丢失决定比较是否成立的约束。文字对照用于文字能表达清楚的差异，不能作为跳过报告图件和技术设计的通用替代。

## 逐页口述

- 开场报正式题目并顺着实际目录转入第一问。背景页先解释对象或术语，再指出图上的位置和当前缺口。
- 文献页说明作者做了什么、该证据支持到哪里、当前课题能借鉴什么。结果页指向图中的组别、趋势或关键位置，再说结论受哪些条件约束。
- 目标页说拟回答什么，内容页说做什么、交付什么。方案页从图中关键位置或步骤讲起，解释对照为什么成立、看什么判定，然后接下一页。按受众调整句长，保持汇报人视角。
- 按[共同发言稿规范](../../references/speaker-script.md)交付独立讲稿并同步备注。讲到“右图”“下一页”时，逐项核对实际图位、标签和页序。开题语气使用“拟、计划、将检验”，已有结果按来源表述。

## 措辞复核

先完成选材和逐页初稿，再核对实证措辞、图表数值、单位、引文和术语与本次材料一致。开题的研究承诺写明材料支持的可行性依据，保留“拟”“提示”等限定。把长句拆成听众能跟上的短句，用实际对象、发现和条件表述研究价值。页码、来源和研究状态疑点记入任务稿。
