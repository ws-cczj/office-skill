# Excel 规划

`planned`。当前提供 [技能入口](SKILL.md) 和职责边界。Excel 专属控制器、文件校验器及测试待实现。

- **整理与汇总** — 通过 Excel COM 清理实验或业务数据，保留原始表、数据类型、单位、清洗规则和跨表关联。多表汇总使用可追溯公式或数据连接，禁止用硬编码常数伪造汇总。
- **公式与制表** — 核对引用、公式一致性、计算错误、表头、单位与表格可读性。在真实 Excel 中重算、保存并重开检查。
- **图表交付** — 通过 Excel COM 导出清晰图表，保留数据映射、单位和图例，工作簿及资产放入 `excel/`。将来如实现 `check_sheet.py`，遵循 [共享只读契约](../../core/README.md)。
