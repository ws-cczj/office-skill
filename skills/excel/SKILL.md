# Excel

先确认字段、单位、分组、去重键和汇总口径。原始数据留作来源，在工作副本内整理。跨表汇总用真实 Excel 公式，核对公式引用、Excel 重算值和源数据。

通过 [Excel COM 入口](README.md) 写入数据、公式、原生表格和图表。保存后从输出版本重开、回读样本范围并验证导出。使用离线只读检查器报告公式与已缓存的错误值。交接工作簿、图表和来源时遵循 [跨应用协作契约](../../references/cross-app-workflow.md)。
