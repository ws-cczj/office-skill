# Word 规划

`planned`。当前提供 [技能入口](SKILL.md) 和职责边界。Word 专属控制器、文件校验器及测试待实现。

- **长文档** — 通过真实 Word COM 设置标题样式层级、图表题注与交叉引用、公式编号、页眉页脚和目录。更新域并保存重开，从最终文档实际分页导出检查图。
- **源稿提取与预检** — 读取结构化提纲、表格、图注及内嵌图件，保留出处、章节关联与原图尺寸。标记跨章节冲突的数值、单位、术语和结论位置以供复核。
- **交付与校验** — 工作副本与已提取素材放入 `word/`。将来如实现 `check_doc.py`，按 [共享只读契约](../../core/README.md) 输出事实与检查范围，视觉验收使用实际页面。
