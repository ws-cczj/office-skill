# 形体复绘

参考图有立体部件时，先认形体，再画轮廓，最后加明暗。四方体、圆柱、空心套筒和切开的剖视图不能共用一个近似轮廓。阅读参考时先定位轴线、主要转角或端面、可见接缝和遮挡顺序，再选择下面的方法。若截图不足以判断结构，可保留经确认的外观并说明不确定处。

**实心圆柱。** 正投影下，两端是同形椭圆，中心相连是一条轴线。两条侧边平行于轴线，并且在同一对切点平顺接入端面。用一个 `cylinder` 操作生成侧壁和前端盖，再按参考图设色。不要独立拉伸端盖来凑接缝。

```json
{
  "op": "add", "kind": "cylinder", "key": "fiber",
  "rear": [1.1, 2.1], "front": [2.1, 1.35],
  "radius": 0.48, "end_ratio": 0.52,
  "fill": "#145B58", "cap_fill": "#082D2B"
}
```

先根据可见端面估算中心、宽高和轴向；被遮住的远端由轴线及外轮廓约束。若参考有轻微透视收敛，可用 `rear_scale` 调整远端大小，同时保持两边与端面相切。端面朝向或比例明显不同的强透视图不能硬套。空心、嵌套或剖开的部件也要保留孔壁、材料层及遮挡；没有合适的原生几何时，可根据实际需求采用轮廓路径，并明确它的可编辑范围。

**验收。** 并排把参考与 Visio 导出图放到相同尺度。先看外轮廓是否有多余尖角、鼓包或缺口，再看轴线、接缝及前后遮挡，最后看颜色和光影。轮廓不对就回改几何参数；形体成立后再润色。保存重开后检查组合可移动、需要独立修改的面可以选中。大图无需逐像素复刻，但不能在分辨率低、明暗近似或整图缩小的情况下把几何失真当作通过。

原生曲线使用 [Visio DrawBezier](https://learn.microsoft.com/en-us/office/vba/api/visio.page.drawbezier)，可在 Visio 里编辑。
