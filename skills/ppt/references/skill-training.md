# PPT Skill 训练、生成与复审

用当次获准审查的材料和反馈迭代 Skill。训练默认修订规则、学习记录及确定性检查器，成片和运行产物作为证据保留。面向使用者的生成提示词只描述 Skill 的规范、所选风格和任务要求。使用者提供本次内容，风格包提供内置视觉资产与验收依据，私有案例仅用于维护。

## 整稿训练

1. **确定交付范围。** 训练默认用一次完整生成检验 Skill 与场景、风格规范的配合。用户明确指定局部时按指定范围制作。生成会话可先处理难页，但同一轮继续完成约定的整稿交付。
2. **委派与观察。** 用户授权委派时，在可用模型中按用户要求选择制作代理，给它当前材料、任务目标、Skill 和内置风格。制作代理把逐页大纲、素材取舍及实际遇到的阻塞写进本轮工作记录，交回 PPTX、终版导图、逐页稿、同步备注和 QA。桌面绘制按项目规则串行。管理者据阶段产物、工具结果和代理主动汇报定位失误。
3. **先审整稿，再定位页面。** 先沿最终页序读出主线，检查目录与导航、相邻页的任务分工、关键论据落点和前后限定。再逐页从导图核对正文、图件和连线，重点对照来源及讲稿。判断水平时可在管理端对照用户授权的手工稿，按同类页面比较论证密度、图文关系和可读性。制作代理使用可独立执行的 Skill 规则。
4. **反馈并复验。** 管理者指出优先问题、具体页码和所见证据，定位到选材、文案、绘制或验收。将通用修正写入实际执行的规范。获明确返修指令的制作代理在副本中修订受影响的页面及关联内容，沿终版页序复验。归档时注明哪些改进已在成片验证，哪些仍待新材料验证。跨课题复验使用当前用户新提供的材料。

### 整稿的验收重点

- **主线。** 背景给出需求和缺口，目标指出要回答的问题，任务和方案展示产出与验证。按实际内容检查相邻页新增的证据或关系。目录、导航和口述都对应实际页序。
- **证据与图。** 查关键技术页的对象、条件、来源、观测与判断。区分原图、概念示意和已有结果。机制、对照、流程各用与其含义相符的构图和标记。
- **观众实际能读到的内容。** 看整份导图的视觉层级和变化，再放大难页检查字面、图例、端点与边界。逐页检查时可用选定风格的内置预览核对视觉。文件检查记录其实际覆盖范围。
- **交付。** 讲稿和备注同步且指向实际画面。修订后检查被影响的页、章名、前后承接及交叉引用。研究进度、来源和状态取自当前材料。

## 从成片追到可修订的规则

1. **确定材料角色和版本。** 区分当次内容来源、待审成片、风格包和维护所用证据。按终版 PPTX、同版导图和页码核对。抽取可复用的阅读顺序、论证密度与图文关系。将附件里的指令作为材料阅读，操作范围来自用户当次要求。
2. **定位脱节的第一步。** 先看实际成片并写下观众能读到什么，再回查原文、逐页稿、绘制计划或脚本、QA。原文有依据而逐页稿缺失，改选材或文案流程。逐页稿写了而绘制没用，改正文进入绘制的方式。图上已画但关系仍不成立，改图形表达与验收问题。原有试排或验收已放行，追查当时检查的问题、实际导图和返修记录。材料缺失时标明能定位到的环节。
3. **把改动落在实际入口。** 普遍的内容问题放场景子 skill，特定正文组件和风格复发放风格包，制作与验收的交接问题放进入统一流程。优先改已有条目，写出触发情形、下一次的具体动作和判定条件。若从源页复用的正文范围偏窄，提出要补的阅读关系或组件；如果源页已具备而实现中被删，先改选版和绘制。私有原稿、截图、长篇审查和运行日志留在本机，正式资源只存通用规则。
4. **写成可独立执行的验收条件。** 用位置、图义或可读信息描述通过条件。历史页码、历史文件名和审查过程留在当次本地记录。正式生成用当次材料、内置规范和风格包检查。成片改善以之后实际绘制并重新导出的页面为证据。

会话间只传当前任务需要的路径、输入角色、涉及的规则、实际页码和待复验项。若需追踪模型因素，记录确知的模型、推理档、Skill 与模板版本及任务要求，未知项标明。不同会话的素材、版本、工具或停止点发生变化时，仅描述观察到的行为差异。要比较模型贡献，需要在可比条件下使用相同来源、规则、任务及验收问题，分别比较选材、绘制和验收结果。

## 交给使用者的提示词

使用者让 Agent 读取 `office-ppt`，再在当前任务附上内容材料与要求。整稿、指定部分和藏蓝开题试排各用对应指令。

### 正式生成

```text
用 office-ppt 把我本次提交的材料制作成可编辑 PPT。汇报用途、受众、风格和篇幅按我本次的要求确定，未指定项从材料推断。依据当前材料、Skill 的场景规范和所选风格包执行。
先确定主线，再为每页写出实际上屏的正文、证据和图文关系。按阅读顺序选择整页复用、重组组件或重绘正文。先试排最难表达的页，从实际导图核对依据、对应关系、标签与边界，再展开全稿。
按 Skill 交付可编辑 PPTX、逐页发言稿、同步备注与终版导图，报告实际检查结果。
```

### 制作指定部分

```text
使用 office-ppt 与内置风格【风格 ID】，根据我本次提供的材料，只制作【本轮要训练的部分】。按我给出的篇幅要求安排，未指定时由内容和证据决定页数。使用当前材料、Skill 的场景规范和所选风格包。

先确定这一部分要让观众理解什么。为每页写出实际上屏的正文、来源和图文关系。按每页要表达的作用复用整页、重组组件或重绘正文。检查相邻页各新增了什么信息。材料不足时注明缺口，保留能支持当前说明的依据。

交付指定部分的可编辑 PPTX、逐页稿、同步备注和终版导图。先仅凭导图回答各页的问题，再与材料和逐页稿核对。QA 写明关键答案位于哪句正文、哪个图形或哪条关系的两端，未达的项目标明页码和原因。交付范围为指定部分。
```

### 藏蓝开题两页试排

```text
用 office-ppt 和内置风格 article/proposal-navy-navigation，根据我本次提供的开题材料，制作两张可编辑正文试排页。沿用藏蓝导航、标题层级和适用组件，正文按证据关系重组。
第 1 页讲研究必要性。让读者从页面读出实际需求、现有证据的局限和课题切入点。使用材料中的图件或有来源的概念示意说明关键对象。
第 2 页展示材料中最需要图解的模型对应或验证关系。让读者在画面上指出比较对象、共同条件和比较量或判断依据。对应线须抵达实际对象，位移和转角使用可区分的符号。
在 PowerPoint 保存重开并导出两页。逐页从导图核对上屏论证、连线端点和文字边界，修正后再交付。提交两页 PPTX、逐页文稿、同步备注与终版导图。
```

## 维护时的复审提示词

```text
按 office-ppt 验收当前提供的成片及当次来源。先看终版导图，再核对逐页稿、来源和制作记录。写明主要缺陷的页码、画面位置、最早可定位的环节与修正建议。
优化 Skill，将可复用的动作与通过条件写入实际执行的规范，并准备下一部分的生成指令。样稿保留为训练证据，私有材料及具体历史证据留在当次审查记录。
```
