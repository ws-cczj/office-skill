# 本页核心信息

用案例将概念与实际应用建立联系。此处是文稿格式演示，不包含可直接发布的课程事实。

在绘制前写清本页要回答的问题及预期落点。为关键事实写到报告节号、图号或表号，把配图对应到真实文件或要绘制的节点与关系。图件未到位时在这里决定缩减证据、绘制可追溯的示意或换版式，再安排对象和尺寸。

不能将页标题复制为“问题与落点”，再将上屏词语列表当成“主阅读关系”。自绘须写明实际要画的对象及其标注、边界、局部与连线含义；需要解释这些内容时，普通概念卡不能替代。开题实例参照[内容与构图选择](../resources/article/proposal-navy-navigation/content-design.md)。

## 页面内容

这是格式示意，正式逐页稿必须把下面的说明替换成实际文案：

- 标题正文：本页真实标题。
- 左栏实际正文：写出来自材料的定义、具体条件及据此得到的判断；不能只填“概念定义、案例条件、结论”这几个栏目名。
- 右栏：引用 `concept-diagram`，其文件和来源由素材清单解析，并写出实际图注或读图结论。
- 页脚：实际来源及页码。

正式稿的关键文字直接供绘制步骤使用。用结构化文稿绘制时，从同一主稿生成或核对本 Markdown 中的实际正文。难页另留一个可以在导图上回答的问题，并标出必须保留的依据或条件，用于[试排与导图核对](../references/visual-quality.md#试排与导图核对)。

## 页面布局与排版

- 复用方式为重组组件。保留现有页头和说明标签，实际案例和配图适合沿左右两栏依次阅读，图件按可读宽度留出空间。
- 标题位于内容区顶部，左右栏在标题下方对齐。
- 左栏约占可用宽度的 45%，右栏约占 55%，栏间留主题定义的间距。
- 标题、正文与来源分别使用主题对应的字号层级；超量时先压缩文案或拆页。
- 由 Agent 计算并记录实际坐标、尺寸、单位和稳定元素 ID，供内置工具在 PowerPoint 中绘制及二次修改；结构化计划的字段见[控制工具](../references/powerpoint-native.md)。

## 图片插入

- 使用 contain 保持示意图完整，不裁掉标签或箭头。
- 保留图注；图片缺失时在任务记录中明确标识，正式交付前解决；实际 PPT 导出的 PNG 用于检查裁剪与排版。
- 若关键关系需要编辑，用原生形状和连接线表达，并逐项核对端点。

## 语义与视觉检查

- 对照所选风格规则检查标题轮廓、字级、间距和边框，核对哪些组件及对齐关系已复用。
- 填充后回读实际位置、尺寸与文字边界；检查中文短尾行和标题换行。若采用数据图表，记录是原图、形状示意还是可编辑数据系列。
- 定义、案例与结论必须来自实际材料，不把本例的占位描述当作正式内容。
- 检查图中文字在最终 PPTX 中可读，来源与正文不重叠。
- 若右图包含流程，核对节点顺序、箭头方向和标签含义。

## 演讲备注

先解释定义，再沿图讲解案例，最后回到本页结论。
