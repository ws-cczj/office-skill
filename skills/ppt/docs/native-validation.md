# 内置 PowerPoint 工具验证

验证日期为 2026-11-16，工具版本为 1.0.0。环境为本机 Windows、Python 3.10、pywin32 312、PowerPoint 16.0。以下描述实测范围，不推断其他机器或未测功能。

## 隔离与实际功能

使用独立 Python 虚拟环境，只安装 pywin32，关闭系统 site-packages，并用 `-I` 执行。环境中没有 `mcp`、`powerpoint_mcp` 或 `pptx` 包；测试启动器另外拦截这些包的导入。完整流程中没有禁止依赖的导入尝试或加载记录。

31 步功能计划在真实 PowerPoint 内一次完成。覆盖从零页开始、中文与 English、带 emoji 的富文本、连续渐变、自由图形、连接线、分组与组内修改、取消分组、原生图表及内嵌工作簿、表格、图片 contain/cover、原生动画、备注、页面复制/移动/删除、快照和 PDF。随后保存、关闭、重开，再读取对象与导出 PNG。三张功能页实际查看过，另核对图表系列、图片实际位置和备注。

另行完成数据编辑测试：把原生图表一项值由 5 改为 7，并修改表格单元格，保存重开后回读正确。源模板按 `[16,2,6]` 选页换序，SlideID 和各页对象与相应源页一致；临时对象可添加后精确删除。普通文本框 AutoSize=1 时修改字体、字号和富文本，最终位置与尺寸保持原基准。

24 项单元测试通过，覆盖输入预检、颜色和几何、Unicode 字符范围、模板文字几何、单元格兼容处理、明确目标、名称/tag、路径冲突、外链图表保护、连接错误、操作中断、重复计划拒绝和跨进程锁。独立只读代码评审发现的路径覆盖、页面命名、自适应与部分对象登记问题已修正，并纳入相关回归。

## 模板保真与兼容

藏蓝导航 0.5.0 源模板的 18 页，在副本保存重开前后的对象快照一致，18 对 1600 × 900 实际导出图逐像素一致。源模板 SHA-256 保持 `400e7563a0f3329f060427a108418ad7dfc8747ab45415a6f7c5baf76f32bf21`，正式预览亦未改。

实测 `.pptx/.pptm/.potx/.potm` 副本的修改、保存、重开和文字回读。宏启用格式的测试文件没有 VBA，未验证宏、签名或宏安全策略。另测 4:3 画幅、中文与 emoji 文件/对象名，以及两个不同目录的同名文稿同时打开。故意激活另一个文稿后，修改仍只落到绑定的完整路径目标；另一个文件哈希与文字未变。

## 与旧流程的对照

PowerPoint 已运行。每个样本使用新的 CLI 进程，执行同一段原生 COM 绘制、保存和 1600 × 900 导出代码，各测试 3 次并交错顺序。旧流程使用原客户端的 open、evaluate、close 三条命令；内置工具使用一条 run 命令。两者都关闭本次目标，不关闭其他文稿。

| 指标 | 旧客户端 + PPT-MCP | 内置工具 |
| --- | --- | --- |
| 三次耗时 | 8.5281、8.2222、8.6511 秒 | 1.5503、1.2729、1.2960 秒 |
| 耗时中位数 | 8.5281 秒 | 1.2960 秒 |
| CLI 调用数 / 次 | 3 | 1 |
| 标准输出字节 / 次 | 2274 | 413–414 |
| 同任务导出图 | 三组均与内置工具逐像素相同 | 三组均与旧流程逐像素相同 |

在这套已有调用流程下，中位耗时约缩短 84.8%，约为原来的 1/6.58。基准包含 CLI 与连接开销，不能解读为 PowerPoint 绘图引擎快了 6.58 倍。没有对旧后端的持久会话优化做测试，也未测模型 token；标准输出字节和调用数量不能直接换算 token 节省比例。原生渲染一致，未证明自动生成的构图或学术内容优于旧版本。

## 分发与限制

正式入口、计划接口、协作锁与依赖已切到内置工具。旧客户端、旧运行环境、旧测试及调研资料归档在本机被忽略的 `runs/20261116-native-control/baseline/`，不进入分享包，不作为自动回退后端。本机详细证据保存在同一运行目录的隔离审计、功能快照、逐像素比较、性能记录和兼容性报告中。

实际发布分享包时，从可分发文件生成，在干净解压目录验证链接、4 个 skill 入口、单元测试与真实隔离制作。验证从分享包的内置模板和当次提供的材料开始，检验结果由本次分发记录保存。

当前仍依赖 Windows 和桌面 PowerPoint；其他 Office 版本、操作系统、复杂公式、特殊媒体、复杂动画、真实 VBA 与签名未实测。脚本扩展可以访问完整对象模型，但接口可达性不等于功能已验收。第三方真实报告的一句话成稿质量仍需按材料、讲稿与最终逐页导出评估。
